# GAMEPULSE Studio 5.3.2 — release notes

- Исправлен зависающий индикатор «Проверяю GitHub Releases…» в GUI: проверка не блокируется занятой редакцией, добавлена собственная защита от параллельных запусков, сообщение о результате и тайм-аут.
- Исправлена проблема пустого `$PSScriptRoot` в начале PowerShell-скрипта обновления.
- Расширен поиск кнопок «Опубликовать запись» и «Пост» в WebView2, сохранён запрет повторной отправки того же материала.
- Исправления VK протестированы **на локальных тестовых страницах**, живую публикацию VK необходимо проверить на ПК перед включением автопилота.
- Windows Go EXE и исходники внутри ZIP. Нужны .NET Framework 4.8 и WebView2 Runtime; C# оболочка собирается из исходников при первом запуске.

## Публикация GitHub Release

1. Создайте Release с тегом `v5.3.2` на https://github.com/Keks1377/GAMEPULSE-Updates/releases/new.
2. Прикрепите *Assets*, не ссылки в тексте: `GAMEPULSE_Studio_Windows_x64.zip` и `SHA256SUMS.txt`.
3. Отметьте выпуск стабильным (не pre-release); проверьте обе загрузки перед нажатием Publish release.
4. Не включайте папки `data`, `model`, `runtime` и VK-профили: это публичный репозиторий.
