# GAMEPULSE-Updates

Официальный репозиторий обновлений **GAMEPULSE Studio для Windows x64** (сообщество VK ID 243631964).

## Статус

- В программу подготовлена интеграция **«Настройки → Обновления»**: автоматическая проверка при запуске и примерно раз в 24 часа.
- Обновление устанавливается **только после подтверждения**, после остановки автопилота и закрытия программы.
- Обновлятор сохраняет папки `data/` (включая VK WebView2-профиль и журнал попыток), `model/`, `runtime/`; перед заменой файлов делает резервную копию.
- В текущий момент **нет опубликованных GitHub Releases**. До появления первого выпуска кнопка проверки не найдёт новую версию.
- Windows-проверка установки и реальная автопубликация через VK ещё должны быть выполнены на компьютере пользователя.

## Как создать первый выпуск v5.3.1

1. Откройте [New release](https://github.com/Keks1377/GAMEPULSE-Updates/releases/new).
2. Выберите **Choose a tag → v5.3.1 → Create new tag v5.3.1**.
3. В заголовке укажите `GAMEPULSE Studio 5.3.1 Update Center`.
4. В **Attach binaries by dropping them here or selecting them** добавьте **ровно два файла**:
   - `GAMEPULSE_Studio_Windows_x64.zip`
   - `SHA256SUMS.txt`
5. Не ставьте отметку **Set as a pre-release** и нажмите **Publish release**.

**Обязательно:** ZIP содержит `GAMEPULSE_Studio.exe`, `StudioEngine.exe`, `GAMEPULSE_VERSION.txt` с текстом `5.3.1` и папку `updater/`. `SHA256SUMS.txt` содержит 64-символьную SHA256-сумму, два пробела и имя ZIP, например:

```text
<64-символьная sha256-сумма>  GAMEPULSE_Studio_Windows_x64.zip
```

Для следующих выпусков используйте теги `v5.3.2`, `v5.3.3` и далее, но **сохраняйте те же имена прикреплённых файлов** и обновляйте версию внутри архива. Программа проверяет только последний стабильный выпуск.

## Безопасность

Никогда не загружайте сюда папки `data/`, `model/`, `runtime/`, VK-токены, личные настройки или профиль браузера. Это **публичный** репозиторий, публиковать в нём можно только проверенные сборки без пользовательских данных.

Обновлятор сверяет SHA256 архива и версию выпуска, делает резервную копию в `backup_updates/`. SHA256 из того же релиза **не является цифровой подписью**: защитите GitHub-аккаунт двухфакторной аутентификацией.

Исходный код обновлятора: [updater/Update-GAMEPULSE.ps1](updater/Update-GAMEPULSE.ps1).
